The design system behind this site

This portfolio runs on a small design system of its own: color tokens, three modes and a few shared components. Every value on this page comes from the site's own stylesheet. The Day, Night and Focus modes mirror my Figma variables experiment, One file, three moods.

Modes

One set of tokens, three modes

Components never use raw colors. They use tokens, and each mode changes the token values, so the whole site switches at once. Try the switch here or in the top right.

Day

Light porcelain background, frosted glass and soft color in the background. The default when your device is in light mode.

Night

The same layout on dark surfaces, with lighter accent and status colors so they stay readable.

Focus

A low-distraction view: no motion, no blur, solid surfaces, larger text and darker body text. It starts on its own when a device asks for more contrast.

Color

Accessibility

Built in, not added later

  • Follows the device's light or dark setting until you choose a mode.
  • Turns off motion when the device asks for reduced motion, and in Focus mode.
  • Starts in Focus mode when the device asks for more contrast.
  • Visible focus rings on links, buttons and controls.
  • The before-and-after sliders, the XCQ search and the reading switch all work with a keyboard.
